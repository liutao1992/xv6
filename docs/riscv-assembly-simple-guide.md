# RISC-V 汇编入门 - 超简单版本

## 什么是汇编语言？

想象你要和计算机说话，但计算机只懂最基本的指令，比如：
- "把这个数字放到那里"
- "把两个数字加起来"
- "如果这个条件成立，就跳到那里执行"

汇编语言就是用人类能理解的方式来写这些基本指令。

## 为什么要学RISC-V？

RISC-V就像是一套"计算机指令的标准"，它的特点是：
- **简单**: 指令不多，容易学
- **现代**: 没有历史包袱，设计很干净
- **开源**: 完全免费，任何人都能用

## 1. 寄存器 - 计算机的"临时存储盒子"

### 什么是寄存器？
把寄存器想象成32个编号的盒子（x0到x31），每个盒子能装一个64位的数字。

```
┌─────┬─────┬─────┬─────┬─────┐
│ x0  │ x1  │ x2  │ x3  │ ... │
│  0  │ ??? │ ??? │ ??? │ ??? │
└─────┴─────┴─────┴─────┴─────┘
```

### 重要的盒子（寄存器）：
- **x0 (zero)**: 永远是0，就像一个空盒子，放什么都会消失
- **x1 (ra)**: 记住"回家的路"（函数返回地址）
- **x2 (sp)**: 指向栈顶，管理函数调用
- **x10-x17 (a0-a7)**: 传递函数参数和返回值

## 1.5 寄存器命名的秘密 - 为什么叫这些名字？

### 寄存器命名很有讲究！

RISC-V的设计者在给寄存器起名字时很用心，每个名字都有特定含义：

#### **基础寄存器的含义**
```
x0  → zero    # zero = 零，永远是0
x1  → ra      # ra = Return Address (返回地址)
x2  → sp      # sp = Stack Pointer (栈指针)
x3  → gp      # gp = Global Pointer (全局指针)
x4  → tp      # tp = Thread Pointer (线程指针)
```

#### **临时寄存器 (Temporary)**
```
x5-x7   → t0-t2    # t = temporary (临时的)
x28-x31 → t3-t6    # 更多临时寄存器
```
**用途**：就像草稿纸，用完就扔，函数调用时不需要保存。

#### **保存寄存器 (Saved)**
```
x8      → s0/fp    # s = saved (保存的), fp = frame pointer (帧指针)
x9      → s1       # s = saved
x18-x27 → s2-s11   # 更多保存寄存器
```
**用途**：就像重要文件，函数调用前后必须保持原样。

#### **参数寄存器 (Arguments)**
```
x10-x11 → a0-a1    # a = argument (参数) + 返回值
x12-x17 → a2-a7    # 更多参数寄存器
```
**用途**：就像信封，用来传递函数的参数和返回值。

### 命名背后的智慧

这套命名解决了一个重要问题：**当函数A调用函数B时，哪些寄存器需要保存？**

```c
// 举个例子
function_A() {
    int temp = 5;        // 可能用 t0 (临时寄存器)
    int result = func_B(temp);  // a0 传参数
    int important = 10;  // 可能用 s0 (保存寄存器)

    // 问题：func_B 会不会破坏这些寄存器的值？
}
```

**RISC-V的聪明解决方案**：
- **t寄存器**：调用者负责保存（如果还要用的话）
- **s寄存器**：被调用者必须保存和恢复
- **a寄存器**：用于传参，调用者知道会被改变

### 特殊寄存器的设计巧思

#### **x0 (zero) - 魔法般的零寄存器**
```assembly
add x1, x0, x2    # 相当于 mv x1, x2 (移动指令)
add x0, x1, x2    # 写入x0无效，结果被丢弃
```
**设计好处**：
- 提供常用的0值，无需单独加载
- 可以模拟其他指令（如移动、丢弃结果）

#### **x8 (s0/fp) - 身兼两职的寄存器**
```assembly
# 既可以作为帧指针
addi s0, sp, 32   # 设置帧指针

# 也可以作为普通保存寄存器
sd   s0, 16(sp)   # 保存s0的值
```

### 在实际代码中的应用

```assembly
# 函数调用的标准模式
function_A:
    # 1. 保存重要寄存器
    addi sp, sp, -16
    sd   ra, 8(sp)      # 保存返回地址
    sd   s0, 0(sp)      # 保存s寄存器（被调用者责任）

    # 2. 使用临时寄存器（不需要保存）
    li   t0, 5          # 临时计算

    # 3. 准备参数
    mv   a0, t0         # 第一个参数

    # 4. 调用函数
    jal  ra, function_B

    # 5. 恢复寄存器
    ld   s0, 0(sp)      # 恢复s寄存器
    ld   ra, 8(sp)      # 恢复返回地址
    addi sp, sp, 16
    ret
```

### 记忆技巧

记住寄存器名称的方法：
- **字母含义**：t=temporary(临时), s=saved(保存), a=argument(参数)
- **用途联想**：ra=return address(返回地址), sp=stack pointer(栈指针)
- **分组记忆**：临时寄存器一组，保存寄存器一组，参数寄存器一组

这套命名不是随意的，而是几十年计算机发展的智慧结晶！

### 简单例子：
```assembly
li x1, 5        # 把数字5放到x1盒子里
li x2, 3        # 把数字3放到x2盒子里
add x3, x1, x2  # 把x1和x2的数加起来，结果放到x3 (5+3=8)
```

## 2. 基本指令 - 计算机能做的事

### 算术运算（就像用计算器）
```assembly
add x3, x1, x2   # x3 = x1 + x2  (加法)
sub x3, x1, x2   # x3 = x1 - x2  (减法)
mul x3, x1, x2   # x3 = x1 × x2  (乘法)
```

### 搬运数据
```assembly
li x1, 100       # 把数字100直接放到x1里
mv x2, x1        # 把x1的值复制到x2里（相当于x2 = x1）
```

### 内存操作（从仓库存取货物）
```assembly
lw x1, 0(x2)     # 从x2指向的地址读取数据到x1
sw x1, 0(x2)     # 把x1的数据存储到x2指向的地址
```

## 3. 控制流 - 让程序"聪明"起来

### 跳转（goto的概念）
```assembly
j label          # 无条件跳转到label标签
label:
    # 这里是跳转目标
```

### 条件跳转（if的概念）
```assembly
beq x1, x2, equal     # 如果x1 == x2，就跳转到equal
bne x1, x2, not_equal # 如果x1 != x2，就跳转到not_equal

equal:
    # x1和x2相等时执行这里

not_equal:
    # x1和x2不相等时执行这里
```

### 函数调用
```assembly
jal ra, function_name  # 调用函数，记住返回地址
# ... 函数执行 ...
ret                    # 返回到调用处
```

## 4. 实际例子 - 理解汇编

### 例子1：计算两个数的和
```c
// C语言版本
int add_numbers(int a, int b) {
    return a + b;
}
```

```assembly
# 汇编版本
add_numbers:
    add a0, a0, a1    # a0 = a0 + a1 (第一个参数 + 第二个参数)
    ret               # 返回结果
```

### 例子2：简单的if语句
```c
// C语言版本
if (x > 5) {
    y = 10;
} else {
    y = 20;
}
```

```assembly
# 汇编版本
    li t0, 5          # t0 = 5
    bgt x1, t0, greater  # 如果x1 > 5，跳转到greater
    li x2, 20         # 否则 y = 20
    j end             # 跳转到结束
greater:
    li x2, 10         # y = 10
end:
    # 继续执行
```

### 例子3：简单循环
```c
// C语言版本
int sum = 0;
for (int i = 1; i <= 5; i++) {
    sum = sum + i;
}
```

```assembly
# 汇编版本
    li t0, 0          # sum = 0
    li t1, 1          # i = 1
    li t2, 5          # 循环上限
loop:
    bgt t1, t2, end   # 如果i > 5，退出循环
    add t0, t0, t1    # sum = sum + i
    addi t1, t1, 1    # i++
    j loop            # 继续循环
end:
    # t0里就是最终结果 (1+2+3+4+5=15)
```

## 5. 在xv6中的应用

### 系统调用（用户程序要求内核帮忙）
```assembly
# 用户程序想要写文件
li a7, 16         # 16是write系统调用的编号
li a0, 1          # 文件描述符（1=屏幕）
la a1, message    # 要写的内容的地址
li a2, 13         # 要写多少字节
ecall             # 陷入内核执行系统调用
```

### 进程切换（操作系统在不同程序间切换）
```assembly
# 保存当前进程的状态
sd ra, 0(a0)      # 保存返回地址
sd sp, 8(a0)      # 保存栈指针
# ... 保存其他寄存器

# 恢复新进程的状态
ld ra, 0(a1)      # 恢复返回地址
ld sp, 8(a1)      # 恢复栈指针
# ... 恢复其他寄存器
ret               # 跳转到新进程
```

## 7. 调试技巧

### 使用GDB查看
```bash
make qemu-gdb                    # 启动xv6等待调试
riscv64-unknown-elf-gdb kernel/kernel  # 启动调试器
(gdb) b main                     # 在main函数设置断点
(gdb) c                          # 继续执行
(gdb) info registers             # 查看所有寄存器的值
(gdb) x/10i $pc                  # 查看当前位置的10条指令
```

### 添加调试输出
在C代码中加入printf来理解汇编：
```c
printf("x1=%d, x2=%d, result=%d\n", x1, x2, result);
```

## 8. 常见错误和解决

### 错误1：忘记初始化寄存器
```assembly
add x3, x1, x2   # 错误：x1和x2没有初始化
```
**解决**：先用`li`指令给寄存器赋值。

### 错误2：跳转标签写错
```assembly
j my_label       # 错误：标签名不匹配
my_lable:        # 注意拼写错误
```
**解决**：仔细检查标签名的拼写。

### 错误3：不理解函数调用约定
```assembly
# 错误：没有保存重要寄存器就调用函数
jal some_function
```
**解决**：学习哪些寄存器需要调用者保存，哪些需要被调用者保存。

## 总结

学习汇编语言就像学习一门新的"外语"，但这门语言非常简单，只有几十个"单词"（指令）。关键是：

1. **多练习**：从简单的例子开始
2. **多对比**：看C代码和对应的汇编代码
3. **多调试**：用GDB一步步看程序执行
4. **不要怕**：汇编看起来复杂，但逻辑很简单

记住：每个复杂的程序都是由这些简单指令组成的！
